# 场景与反例

12小时观测，每小时三处设备、三组两两重叠记录。首小时A120、B110、C90，交集40、30、20，可行联合人数230至250。A100、B80、交集30时联合人数150。A、B、C都100但AB80、AC80、BC0，无可行三方交集，必须隔离。脏样例含缺测、同版冲突、BOM、短行、重复与中文换行。

## 维护期场景

探A维护后只补了A的新校准（`offset=2`），B、C仍用维护前历史校准：A段计入“已采信”，B、C段进入正式区间但标为“未确认沿用”。当天客流仍可交出（正式区间包含两类），但交接时不得把“未确认沿用”并入已采信人数。逐段页面显示“A 120→122、依据 维护后探头A新校准”，以及该段修正前 230–250、修正后 232–252。

若维护窗口内 B 尚未补齐任何校准，则该时段整段隔离而不是只用 A 侧拼人数；页面给出修正前区间，便于核对漏计规模。补齐 B 的校准后重跑，只重算受影响的时段，其余时段的结果直接复用。

同一校准重复提交只应用一次；同一校准编号内容不同则相关观测隔离为 `CALIBRATION_CONFLICT`，账本与审计保留两条冲突记录。保存失败返回 503，上一批次及其复核版本不受影响。
